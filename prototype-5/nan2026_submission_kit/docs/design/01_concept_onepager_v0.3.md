# 컨셉 원페이저 v0.3 — 공명 서바이버 (가칭)

> v0.3 / 2026-08-10 / v0.2 대체. 스토리 바이블 v0.2와 정합.
> 확정 사항: ① 세계관 = '말소된 실제 역사' 프레임 ② 장르 = 뱀서 코어 + **공명(共鳴) 버스트 액션**
> ③ 아트 톤 = 저해상도 픽셀 + 연출 씬 고해상도 일러스트 하이브리드 ④ 타겟 = 글로벌 Steam

## 1. 로그라인 & 정체성

**"무림은 실재했고, 역사에서 지워졌다. 유일하게 그 기록을 읽은 독자가, 지워진 이름들을 기억으로 되살려 군단을 이끈다 — 그리고 때로는, 그들의 삶을 직접 살아본다."**

- 장르: **소환 군단 서바이버 + 공명 버스트 액션** (뱀서 코어 × TFT 시너지 × 순간 캐릭터 액션)
- 두 줄 차별화:
  1. 본체는 싸우지 않는다. 기억으로 되살린 군단이 싸운다. 편성이 곧 빌드다.
  2. 단, 공명의 순간 — 독자는 인물에 빙의해 그의 무공을 직접 휘두른다. **'읽는 자'가 '살아보는 자'가 되는 순간.**
- 레퍼런스: Vampire Survivors + TFT + Slay the Spire + Hades(조각 서사·보스 관계) + 산나비(연출·서사 전달) + 지워진 역사 프레임(자체)

```
이동/회피(경공) — 군단 자동 전투
   ↓                                ┌──────────────────┐

   ↓                                │ 공명 발동: 지정   │
신원(伸冤) 각성 = 절기 해방          │ 인물로 6~10초    │
   ↓                                │ 직접 조작 버스트  │

```

## 3. 공명(共鳴) 시스템 스펙 초안

### 3-1. 기본 규칙
| 항목 | 스펙 (초안) | 비고 |
|---|---|---|
| 대상 지정 | 편성된 **핵심 인물** 중 1인을 런 시작/편성 화면에서 지정 | 전투 중 선택 휠 배제 — 템포 우선. 지정 변경은 층간 휴식에서 |
| 대상 범위 | 핵심 인물 8~10인 한정 (잡졸·신수·검령 불가) | 비용 통제 + 서사 정당화: "이야기를 아는 인물만 공명 가능" |
| 게이지 충전 | 군단 처치 수 비례 + 완벽 회피(경공 저스트) 보너스 | 본체 조작 숙련이 충전 효율로 보상됨 — 조작 재미의 사전 연결 |
| 발동 | 원버튼, 게이지 전량 소모 | |
| 지속 | 기본 6초 + 처치·저스트로 최대 10초 연장 → 전용 피니시로 종료 | 연장 메커니즘 = 버스트 중에도 잘할 이유 |
| 피해 처리 | 공명 중 본체 피해 없음. 받는 피해는 **잔여 게이지 감소**로 전환, 소진 시 강제 해제 | "인물이 도윤을 지킨다" 판타지 + 리스크 유지 |
| 공명 중 군단 | 자동 전투 유지 + 공명 인물과의 시너지 태그 1단계 임시 상승 | 편성과 액션의 연결 고리 |

### 3-2. 무브셋 설계 원칙
- **4버튼 이내**: 기본 연격 / 특수기 / 이동기 / 피니시. 콤보 트리 없음 — 짧은 버스트에 최적화된 컴팩트 액션.
- 인물별 무브셋 = 무공 계열 태그와 일치 (검/도/권장/암기/진법) → 계열당 베이스 무브셋 1종 + 인물별 특수기·피니시 차별화 (계열 5종 × 변형 = 비용 통제의 핵심).
- 예시 컨셉:
  - 검 계열(백도맹 검수): 직선 연격 + 발도 대시, 피니시 = 일섬
  - 암기 계열(흑귀회 살수): 고속 점멸 + 표창 산탄, 피니시 = 표식 동시 격발
  - 진법 계열(군사형 인물): 유일한 비액션 변형 — 짧은 전장 지휘(군단 일제 지정 공격) — 액션 비선호 유저의 선택지
- **진무영 (진 엔딩 후 해금)**: 회귀 검격 무브셋 — 피니시 '한 번 더': 버스트 종료 시점을 1회 되감아 재실행. 그의 회귀를 손맛으로 번역.

### 3-3. 성장·서사 연동
- 인물 경지 상승 → 무브셋 수치 강화 / **신원 단계** → 특수기·피니시가 '진짜 절기'로 교체 (오명 시절의 뒤틀린 기술 → 복원된 본래 무공. 신원의 시각적 보상).
- 공명 중 화면 가장자리에 인물의 기억 플래시 1줄 (예: 첫 공명 시 "…이 손의 굳은살은, 이렇게 만들어진 거였구나") — 인연 이벤트 트리거와 연결.
- 첫 공명은 스토리 이벤트로 연출 (산나비식 연출력 투입 지점).

### 3-4. 검증 계획 (모듈형)
- **P1 프로토타입**: 순수 뱀서 코어 (군단 4체 + 시너지 2종). 공명 없음. 기본 재미 검증.
- **P2**: 공명 1종(검 계열) 추가. 검증 질문: "버스트가 런의 템포를 살리는가, 끊는가" / "충전→발동 리듬이 기대감을 만드는가".
- 실패 시 공명은 절단 가능 (코어 루프 독립성 유지). 성공 시 계열 5종으로 확장.

## 4. 시스템 요약 (변경 없는 확정 사항)

- 시너지 태그 3축: 소속(백도맹/흑귀회/무명교/무소속) · 무공 계열(검/도/권장/암기/진법) · 오행. 편성 슬롯 6~8체.
- 계약 3카테고리: 핵심 인물(공명·신원 대상) / 검령·명병(장착 시너지) / 신수·요괴(물량, 무한 확장).
- 진행: 3권 × 권당 3~4장 + 권말 보스. 장 랭크 C~S++. 클리어 후 사관(史觀) 모드(Heat식).
- 메타: 헌책방 복원 (서가/필사대/독서등/다락방) + 현대 조사 파트(1.0 비전투, 권당 3~4씬).
- 서사: 스토리 바이블 v0.2 (지워진 역사 / 백지회 / 진무영 3층 구조 / 신원 테마) 그대로.

## 5. 아트 톤 (확정)

- **인게임: 저해상도 픽셀** (캐릭터 32~48px급) — 뱀서식 물량 대응, 세피리아 계열의 검증된 톤.
- **연출: 고해상도 일러스트** — 스토리 씬, 인연록 초상, 첫 공명 이벤트, 보스 등장 컷.
- 공명 발동 연출 = 두 톤의 교차점: 발동 순간 인물 일러스트 컷인 → 픽셀로 복귀 (뱀서라이크와의 시각적 차별화 포인트이자 스팀 클립·쇼츠용 순간).
- 파이프라인: 아트 파이프라인 v0.1 문서 기준 (AI Studio 앱 제외 확정).

## 6. 서사 ↔ 공명 정합

| 요소 | 의미 |
|---|---|
| 공명 그 자체 | 읽는 자 → 살아보는 자. 신원 테마의 체험화 |
| 게이지 충전 (기억이 쌓임) | 군단과 함께 싸운 시간이 인물과의 동조를 깊게 함 |
| 피해의 게이지 전환 | 인물이 도윤을 지킨다 — 계약의 쌍방향성 |
| 신원 시 절기 교체 | 이름을 되찾은 자만이 본래의 무공을 보여준다 |
| 무영 공명 (진 엔딩 후) | 수만 회차를 살아낸 검을, 마침내 플레이어가 잡는다 |

## 7. 리스크 갱신

| 리스크 | 대응 |
|---|---|
| 무브셋 제작비 | 계열 5종 베이스 + 인물별 변형 구조. 대상 8~10인 한정. 4버튼 상한 |
| 공명이 템포를 끊을 위험 | P2 단독 검증, 절단 가능한 모듈 설계 (§3-4) |
| 액션 비선호 유저 | 진법 계열(지휘형) 제공 + 공명 미사용 클리어 가능 밸런스 |
| 두 재미의 정체성 분산 | 공명은 어디까지나 '버스트'. 화면 점유 시간 목표: 런의 10~15% 이내 |
| (기존 리스크) | v0.2 리스크 표 유지 — 라이팅 리소스, 스코프 가드레일, Steam AI 고지 등 |
