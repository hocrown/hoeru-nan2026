# P1 프로토타입 스펙 v0.1 — 개발 착수 문서

> 2026-08-10 / 시너지 스펙 v0.1 · 핵심 인물 시트 v0.1 기준. 수치는 전부 초기값(플레이 테스트로 조정 전제).
> **P1의 유일한 목적: "뱀서 코어(군단 자동전투 + 시너지 + 편성)가 그 자체로 재미있는가" 검증.** 공명·서사·메타 프로그레션 전부 배제.

---

## 1. 스코프 정의

| 포함 | 제외 |
|---|---|
| 이동/회피 조작, 군단 자동전투 | 공명(P2), 스토리/대사 전부 |
| 유닛 4종 + 적 3종 + 미니보스/장보스 각 1 | 오행, 신원, 인연 이벤트 |
| 시너지: 백도맹 2/4 + 검 2/4 | 헌책방/메타 프로그레션, 장삼 계승 |
| 승급 → 호명 3택1 (풀 8종) | 사관 모드, 랭크 산정 |
| 1개 장(章), 12분 | 세이브, 옵션, 로컬라이징 |

- 엔진 권장: **Godot 4** (2D 특화·무료·경량, 물량 렌더링은 MultiMesh/서버 API로 대응) — 팀에 Unity 숙련자가 있다면 Unity도 무방. 프로토타입 단계 전환 비용은 낮음.
- 목표 제작 기간: 2~3주 (1인 개발 가정).

## 3. 유닛 스펙 4종

공통: 소환수는 본체 주위 궤도 슬롯에 배치, 인접 적 자동 탐색. DPS 기준 단위 = 기본 전투력 100(삼류) 환산.

| 유닛 | 태그 | 행동 | 수치 (초기값) |
|---|---|---|---|
| **유서린** (인물) | 백도맹·검·수 | 근거리 3연격, 3타째 관통 검격 | 공격 주기 0.9s, 타당 12, 3타째 20·관통 |
| **백랑(白狼)** (신수) | 백도맹·(오행 미적용) | 근접 추격형 — 가장 가까운 적 물기 | 주기 0.7s, 타당 8, 이속 260 |
| **백학(白鶴)** (신수) | 백도맹·(오행 미적용) | 원거리 — 깃털 투사체 2발 | 주기 1.4s, 발당 10, 사거리 420 |
| **유엽검령(柳葉劍靈)** (검령) | 검·(장착형) | 장착 인물 공속 +10% + 검 태그 1 기여 | 유서린 장착 기본 상태로 시작 |

- 승급 풀 8종(호명 3택1): 위 4종의 중복(경지 상승: 티어당 스탯 ×1.15~) + 더미 유닛 4종 (백도맹 잡졸형 2, 무소속 검령 1, 회복 포션형 1) — 선택지 다양성 확보용 최소 구성.
- 경지: P1에서는 삼류→절정(4티어)까지만. 배율은 밸런싱 시트 '경지체계' 탭 값 사용.

| 시간 | 내용 | 밀도(동시 개체 목표) |
|---|---|---|
| 0:00~2:00 | 잡귀 저밀도 — 조작·자동전투 학습 | 8~15 |
| 2:00~4:00 | 잡귀+원귀 혼성, 첫 승급 3~4회 발생 구간 | 20~35 |
| 4:00~6:00 | 돌귀 등장, 포위 스폰 패턴 1회 | 35~50 |

| 6:30~9:00 | 밀도 상승, 검4/백도맹4 도달 기대 구간 | 50~80 |
| 9:00~11:30 | 최고 밀도 웨이브 + 돌귀 다수 | 80~120 |

## 7. 검증 설계 (KPI)

| 질문 | 지표 | 목표 |
|---|---|---|
| 코어가 재미있는가 | 테스터 재플레이 의사 (5점 척도) | 평균 3.8+ |
| 시너지 체감이 명확한가 | "단계 상승을 인지했는가" 인터뷰 + 검4 도달률 | 도달률 60%+ |
| 검령 장착이 퍼즐인가 | 장착 변경 시도 횟수 로그 | 런당 1회+ |
| 난이도 곡선 | 사망 시각 분포 | 6:00(미니보스)·11:30(보스) 부근에 집중, 초반 2분 사망 5% 미만 |
| 조작 손맛 | 저스트 회피 시도·성공률 로그 | P2 게이지 설계의 입력 데이터 |
- 로그 수집: 사망 시각/원인, 승급 선택 이력, 태그 도달 시각, 저스트 판정. CSV 덤프면 충분.

## 8. P1 에셋 파이프라인 — sprite-gen 통합

공유된 **aldegad/sprite-gen** (Apache-2.0, Python)을 P1 에셋 제작의 기본 경로로 채택.

- 정체: Codex/Claude 에이전트용 스프라이트 시트 생성 스킬. 워크플로가 단일 경로로 고정되어 있음:
  `sprite-request.json → 레이아웃 가이드+프롬프트 → 이미지 생성(상태별 행) → 크로마키 알파 추출 → 연결 요소 분석으로 프레임 분리 → 정방형 프레임 정렬 → sprite-sheet-alpha.png + manifest.json(frame_layout)`
- **가치**: AI 이미지 생성의 최대 난점(들쭉날쭉한 프레임 정렬·배경 제거·아틀라스화)을 결정론적 스크립트로 처리 → 엔진에 바로 임포트 가능한 아틀라스+매니페스트 산출. 컴포넌트-행 방식이 캐논 엔진 (고정 그리드 컷은 폐기됨) — 요청 JSON 작성 시 이 방식 기준으로.
- **P1 적용 계획**:
  1. 적 3종 + 신수 2종: sprite-gen 전량 생성 (idle/move/attack/death 4상태) — 품질보다 속도.
  2. 유서린·도윤: sprite-gen 초벌 → Aseprite 수작업 보정 (핵심 실루엣만).
  3. manifest.json의 frame_layout → Godot SpriteFrames 변환 스크립트 1개 작성 (1회성 유틸).
- **주의**: 이미지 생성 백엔드 품질에 종속 — 아트 파이프라인 v0.1 §4의 마스터 시트 참조 원칙 병용 (캐릭터당 참조 이미지 고정 후 상태 행 생성). Apache-2.0이므로 상용 사용 가능, NOTICE 고지 유지.
- 아트 파이프라인 문서 §3-2에 본 툴 추가 (Retro Diffusion·PixelLab과 병용: sprite-gen은 '정리·아틀라스화' 담당, 생성 품질은 백엔드 담당).
