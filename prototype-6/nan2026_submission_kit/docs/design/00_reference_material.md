# 로그라이트 게임 기획 레퍼런스 자료집

> 작성일: 2026-08-10 / 목적: 로그라이트 류 (아케이드 액션 or 디펜스) 게임 기획을 위한 사전 자료 확보

---

## 1. 로그라이트 장르의 핵심 설계 축

로그라이트가 "매번 새로운 경험 + n회차 플레이"를 만들어내는 구조는 크게 4가지 축으로 정리된다.

### 1-1. 런(Run) 구조
- 한 판(런)은 짧게는 15~40분. 죽으면 런 내 성장은 리셋.
- 절차적 생성(맵/이벤트/적 배치)과 랜덤 보상 제시로 매 런이 달라짐.
- 핵심은 "랜덤 제시 + 플레이어 선택": 완전 랜덤이 아니라, 랜덤하게 주어진 선택지 중에서 플레이어가 고르게 하여 전략성을 확보.

### 1-2. 빌드 조합 (런 내 성장)
- 아이템/카드/유물/스킬이 서로 시너지를 내며 곱연산으로 강해지는 구조.
- "빌드가 완성되는 순간의 쾌감"이 장르 도파민의 핵심 → 먼치킨물의 각성 서사와 정확히 겹침.
- 설계 포인트: 태그/키워드 시스템(속성, 무기군, 트리거 등)으로 조합 폭발을 관리.

### 1-3. 메타 프로그레션 (런 밖 성장)
- 죽어도 남는 자원으로 영구 강화, 신규 캐릭터/아이템 해금.
- "패배해도 전진했다"는 감각을 주어 n회차를 견인.
- 과하면 실력이 아닌 노가다 게임이 되므로, 해금은 '선택지 확장' 위주 / 수치 강화는 보조로.

### 1-4. 난이도 계층
- 승천(Ascension), 하드 모드, 저주/열기(Heat) 시스템 등으로 클리어 이후의 목표 제공.
- 플레이어가 스스로 난이도 제약을 고르게 하는 방식(Hades의 Heat)이 리텐션에 유리.

## 2. 참고 게임 분석

### 2-1. Slay the Spire (덱빌딩 로그라이트의 교과서)
- **런 구조**: 3막(+히든 4막), 분기 맵에서 전투/이벤트/상점/휴식/엘리트 경로를 선택.
- **조합 시스템**: 캐릭터별 카드풀 + 유물(패시브) 조합. 카드 획득은 "3장 중 1장 선택" — 랜덤 제시 + 선택 구조의 원형.
- **난이도**: 승천(Ascension) 1~20단계. 클리어할 때마다 한 단계씩 페널티가 누적되는 계단식 난이도.
- **n회차 동력**: 캐릭터 4종의 완전히 다른 아키타입, 데일리 챌린지, 시드 공유.
- **배울 점**: 
  - 카드 '제거'도 보상이라는 설계 (덱 압축 = 성장).
  - 적의 다음 행동을 미리 보여주는 인텐트 시스템 → 랜덤 속에서도 계산 가능한 전투.
  - 유물 하나가 런 전체의 방향을 트는 "빌드 어라운드" 아이템 설계.

### 2-2. Vampire Survivors (아케이드 로그라이트의 재발명)
- **런 구조**: 30분 생존. 조작은 이동뿐, 공격은 자동 → 극단적 저마찰 조작.
- **조합 시스템**: 무기 6 + 패시브 6 슬롯. 특정 무기+패시브 조합 시 '진화'로 각성 무기 획득 → 레시피 발견 자체가 콘텐츠.
- **성장 감각**: 레벨업마다 4지선다 선택. 후반부 화면을 뒤덮는 압도적 파워 판타지 = 게임화된 먼치킨물.
- **메타 프로그레션**: 골드로 영구 스탯 강화, 캐릭터/스테이지/유물 해금. 해금 조건이 도전과제처럼 설계되어 회차 목표를 자연 생성.
- **배울 점**:
  - "빌드의 완성형(진화)"을 명시적으로 만들어 목표 지향 플레이 유도.
  - 저조작 + 고밀도 피드백(숫자, 이펙트, 물량)으로 아케이드성 확보.
  - 개발 리소스 대비 효율이 극도로 높은 구조 (에셋 재활용 + 수치 조합).

### 2-3. 세피리아 (Sephiria)
- 던그리드를 만든 국내 인디 개발사 TEAM HORAY의 탑다운 픽셀 액션 로그라이트. 2025년 4월 앞서 해보기, 2026년 7월 31일 정식 출시.
- **세계관**: 탑 꼭대기 마을의 토끼가 되어, 멸망의 운명을 바꾸기 위해 탑을 '내려가는' 구조 (탑등반물의 역전 컨셉).
- **조합 시스템 (핵심 차별점)**: 격자 인벤토리에 아티팩트를 배치하고, '석판'이 인접한 아티팩트를 강화하는 **인접 배치 퍼즐** 시스템. 인벤토리 관리 자체가 미니게임이자 빌드 구성.
- **성장 요소**: 아티팩트 + 무기 강화 + 재능 트리 + 운명 각인 + 코스튬(대량, 이벤트 해금) 등 다층 구조.
- **기타**: 4인 협동 멀티, 용병 고용, 하드 모드, 속성 피해 4종(물리/화염/얼음/번개) 기반 계수 시스템.
- **배울 점**:
  - "배치"라는 공간적 의사결정을 빌드에 결합 → 같은 아이템도 배치에 따라 다른 빌드가 됨.
  - 한국 인디 시장에서 검증된 아트 톤(아기자기한 픽셀) + 하드한 액션의 조합.
  - 층(플로어) 단위 진행 + 미니보스/층보스 보상 리듬.

### 2-4. 보조 참고 (필요 시 추가 조사)
- **Hades**: 서사와 로그라이트의 결합. 죽음마저 스토리로 흡수. Heat 시스템(자기 선택형 난이도).
- **Dead Cells**: 액션 손맛 + 무기 다양성. 세포(메타 재화) 기반 해금.
- **뱀서라이크 국산 사례**: 나이트 리퍼, 노마드 서바이벌 등 — 소규모 팀의 시장 진입 사례로 참고 가치.

## 3. 먼치킨 / 성장물 컨셉 분석

웹소설 성장물의 서사 장치는 로그라이트의 시스템과 구조적으로 동형(同型)이다. 아래는 게임 시스템으로 번역 가능한 요소 중심 정리.

### 3-1. 나 혼자만 레벨업 (Solo Leveling)
- **핵심 장치**: 최약체 헌터가 '시스템'(상태창, 퀘스트, 레벨업)을 독점 각성 → 유일하게 성장 가능한 존재.
- **게임 번역 포인트**:
  - **상태창/시스템 메시지 UI**: 성장을 텍스트로 명시해주는 연출 자체가 도파민. 레벨업/스킬 획득 팝업의 연출 강화.
  - **일일 퀘스트/페널티 존**: 강제 반복 훈련 → 데일리 런, 챌린지 모드로 번역 가능.
  - **그림자 군단**: 쓰러뜨린 적을 아군으로 편입 → 처치한 몬스터를 유닛/소환수로 수집하는 시스템 (디펜스 장르와 특히 궁합 좋음).
  - **직업 전직/히든 퀘스트**: 특정 조건 달성 시 클래스 각성 → 런 중 히든 조건 발견형 콘텐츠.
  - **재도전 서사**: "이중 던전에서 죽을 뻔한 뒤 회귀적 성장" = 죽음이 성장의 트리거라는 로그라이트 문법 그 자체.

### 3-2. 하남자의 탑 공략법
- **개요**: 꾸찌꾸찌 작, 2024년 문피아 연재 시작. 문피아에서 회당 평균 구매수 최상위권을 기록하며 '하남자물'·'탑딸깍물'·소환사물 트렌드를 만든 작품. 네이버웹툰화(2025.12~).
- **설정**:
  - 지구 곳곳에 검은 탑 등장. '플레이어'만 입장 가능, 층마다 6개월 제한시간, 실패 시 탑 붕괴 → 국가 단위 재해.
  - 탑 밖에서는 능력 사용 불가, 하루 1회 입장 제한 등 **제약 설계**로 차별화.
  - 주인공은 겁 많고 안전제일주의인 '하남자' 소환사. 가챠로 SSR 암살자를 뽑아 층 기록을 경신.
- **게임 번역 포인트**:
  - **소환사 + 가챠 빌드**: 본인은 약하고, 뽑은 소환수가 싸움 → 디펜스/오토배틀러와 직결되는 구조. 런 중 소환수 가챠 = 랜덤 제시+선택.
  - **층 단위 탑 공략 + 제한시간**: 웨이브/스테이지 구조와 기록 경신(층별 랭크 S++) 시스템으로 번역.
  - **하남자 컨셉**: "겁쟁이지만 시스템빨로 먼치킨" — 캐릭터성/톤앤매너 차별화 포인트. 세피리아의 토끼처럼 약해 보이는 주인공이 압도하는 갭 재미.
  - **입장 제한**: 스태미나/일일 도전 구조의 서사적 정당화.

### 3-3. 화산귀환
- **핵심 장치**: 화산파 최후의 생존자 청명이 100년 뒤 미래에 회귀 → 전성기 기억(지식)은 그대로, 몸은 처음부터.
- **게임 번역 포인트**:
  - **회귀 = 로그라이트 런 그 자체**: "지식은 남고 몸은 리셋" — 플레이어 스킬과 메타 지식이 남는 로그라이트의 완벽한 서사적 은유.
  - **문파 재건**: 런을 반복하며 거점(마을/문파)이 성장하는 메타 프로그레션 → Hades의 저택 개조, 다키스트 던전의 마을 시스템.
  - **기연/심득**: 과거 지식으로 남들이 못 찾는 기연을 선점 → 히든 룸, 조건부 이벤트, 회차 한정 선택지.
  - **무공 체계**: 심법(패시브 코어) + 초식(액티브) 구조는 무기+패시브 조합 시스템과 자연 호환. 동양 무협 톤의 로그라이트는 상대적으로 블루오션.

### 3-4. 성장물 → 로그라이트 공통 문법 요약
| 웹소설 장치 | 게임 시스템 번역 |
|---|---|
| 상태창/시스템 메시지 | 성장 피드백 UI, 레벨업 연출 |
| 회귀/N회차 | 런 반복 + 메타 지식 축적 |
| 히든 퀘스트/기연 | 조건부 해금, 시크릿 이벤트 |
| 각성/전직 | 빌드 완성(진화), 클래스 분기 |
| 그림자 군단/소환수 | 유닛 수집, 디펜스 배치 |
| 탑 등반 | 층 구조, 층별 랭크/기록 |
| 문파/길드 재건 | 거점 성장형 메타 프로그레션 |

## 4. 장르 방향 비교: 아케이드 액션 vs 디펜스

### A안. 아케이드성 액션 로그라이트 (뱀서라이크/세피리아 계열)
- 강점: 즉각적 손맛, 짧은 런, 모바일/PC 양쪽 대응 용이, 시장 검증 완료.
- 리스크: 뱀서라이크는 이미 레드오션 → 조합 시스템의 독창성(예: 세피리아식 배치 퍼즐, 무협 무공 체계)이 필수.
- 궁합 좋은 컨셉: 화산귀환(무공 액션), 세피리아(배치 빌드).

### B안. 디펜스 로그라이트 (타워/유닛 배치 계열)
- 강점: 소환사/군단 컨셉과 직결, 전략성 깊이, 오토배틀 요소로 방치형 확장 가능.
- 리스크: 아케이드 대비 초반 학습 곡선, 웨이브 밸런싱 난이도.
- 궁합 좋은 컨셉: 나혼렙(그림자 군단), 하남자의 탑(소환사 가챠 + 층 방어/공략).
- 참고 게임(추가 조사 후보): Dome Keeper, 러시아워(방치+디펜스), Emberward, 킹덤 러쉬 로그라이트 변형들.

### 절충안. "소환수 수집형 아케이드 서바이버"
- 본체는 뱀서식 이동 회피, 화력은 수집한 소환수가 담당 → 두 장르의 교집합.
- 나혼렙 그림자 군단 판타지 + 뱀서 조작 저마찰 + 하남자식 가챠 선택.

## 5. n회차 / 난이도 설계 체크리스트 (기획 시 검토용)

1. **런 다양성**: 캐릭터(또는 시작 소환수) 최소 3종 이상, 아키타입이 겹치지 않게.
2. **조합 공간**: 아이템 태그 시스템으로 시너지 관리. "빌드 어라운드" 아이템을 티어별 배치.
3. **랜덤 제시 + 선택**: 모든 보상은 N개 중 택1. 리롤은 자원 소모로.
4. **메타 프로그레션**: 해금(가로 확장) 중심, 수치 강화(세로 확장)는 총 전투력의 20~30% 이내 권장.
5. **난이도 계층**: 클리어 후 승천/하드 모드. 가능하면 플레이어 선택형 제약(Heat식).
6. **기록 시스템**: 층별/스테이지별 랭크(하남자의 S++식) → 회차 목표 자동 생성.
7. **발견형 콘텐츠**: 진화 레시피, 히든 조건, 시크릿 캐릭터 → 커뮤니티 위키 형성 유도.
8. **죽음의 서사화**: 사망을 회귀/귀환으로 포장해 세계관과 시스템을 일치시킬 것 (화산귀환/나혼렙 문법).
