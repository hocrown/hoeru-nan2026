# 회루(回樓)

*NAN 2026 · 게임 소개 및 설명 문서*

**한 줄 소개** — 지워진 역사 속 무림의 인물들을 '기억'으로 되살려 군단을 이끄는, 수묵 미감의 **소환 군단 서바이버** 로그라이트. *군단이 싸우고, 당신은 단 10초 동안 전설이 된다.*

## 1. 게임 개요

무림은 실재했던 시대였으나, '무명교'라는 집단에 의해 역사에서 통째로 말소되었다. 유일하게 남은 기록(소설로 위장된 실록)의 유일한 독자였던 플레이어는 그 기록 속 세계로 떨어져, 지워진 인물들을 기억으로 되살려(소환) 함께 싸우며 이야기의 결말 — 역사의 복원 — 을 향해 나아간다. 본 제출작은 그 프롤로그에 해당하는 **6분 분량의 1개 장(章)** 데모다.

## 2. 게임 방법

| 항목 | 내용 |
|---|---|
| 목표 | 6분간 생존하며 군단을 키우고, 2분 20초의 중간보스 '광검수'와 5분 30초의 최종보스 '타락한 대협'을 격파하면 승리 (클리어 랭크 C~S++ 산정) |
| 조작 (PC) | 이동: WASD / 방향키 · 경공(회피 대시, 무적 프레임): Space · **공명(빙의 버스트): E** · 레벨업 선택: 1/2/3 키 또는 클릭 · 일시정지: P · 음소거: M |
| 조작 (모바일) | 드래그: 이동 · 우하단 버튼: 경공 / 공명 |
| 핵심 규칙 | 플레이어 본체는 공격하지 않는다. 적 처치로 얻는 '원기'로 레벨업하면 **호명(呼名)** — 3택1 소환 가챠 — 가 열린다. 같은 인물을 중복 선택하면 경지(삼류→화경)가 오르고, **경지에 따라 인물의 모습이 변한다**. |
| 공명 | 저스트 회피·위험 근접·처치로 게이지 충전 → E로 발동: 유서린에 빙의해 짧은 버스트 동안 직접 벤다. 보스급은 '패기'로 공명 피해를 40% 경감 — 공명은 정예 정리용, 보스전에선 보조. |
| 시너지 | 소환수의 태그가 모이면 발동 — 백도맹 2: 호신강기(피격 1회 무효) / 4: 협공(+25%) · 검 2: 관통 검기 파동 / 3: 일섬(12초마다 전장 참격). 화면 좌측 패널에 표시. |
| 종료 조건 | 승리: 최종보스 격파 (직후 짧은 에필로그 연출) · 패배: 기력 0 — "책이 덮였다" 연출과 함께 첫 페이지로 회귀 (즉시 재도전, "N번째 열람" 누적 표시) |
